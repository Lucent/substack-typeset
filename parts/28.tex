\part{Meaning through story}
\epigraph{We use story to run counterfactuals we can't run in life: to see what would happen if one knob changed and the world's rules became legible. Mystery-box structures work when they promise a recoverable rulebook rather than just a twist, because the satisfaction is the model snapping into place. Different minds optimize different payoffs---some for world-understanding, some for clean emotional landing---but the engine is the same.}{}
